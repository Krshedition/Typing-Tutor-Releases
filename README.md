# Typing Tutor — Official Releases & Updates

This repository serves as the official distribution channel and auto-update endpoint for the **Institutional Offline-First Typing Tutor** Windows desktop application.

## Downloads
Download the latest Windows setup installer (.exe / .msi) from the **[Releases](https://github.com/Krshedition/Typing-Tutor-Releases/releases)** section.

## Verification
All release artifacts are cryptographically signed with Minisign Ed25519 digital signatures.
